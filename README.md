# Hellforge — Releases

Public changelog and release archive for [Hellforge](https://hellforgetool.com), a Windows
automation macro for Diablo IV.

- **Changelog**: see [CHANGELOG.md](CHANGELOG.md), newest first.
- **Downloads**: each tagged release includes the installer (`Hellforge-<version>-setup.exe`)
  and the portable build (`Hellforge-<version>-portable.zip`) as release assets. The official
  download page is [hellforgetool.com/portal/download](https://hellforgetool.com/portal/download)
  (requires a license); this repository exists as a public, versioned mirror of what shipped
  and when.

This repository does not contain the Hellforge source code (private) and does not accept
issues or pull requests — it is published automatically by the Hellforge build pipeline.
